# KhoUI — Product Truth & Context

## 1. Product Overview
- **Name:** KhoUI (LuminaShop)
- **Tagline:** Vietnam's Premium Website Template & Source Code Marketplace
- **Purpose:** Provide software engineers, agencies, and businesses with production-ready, beautifully crafted full-stack templates (Next.js 16, Tailwind CSS 4, GSAP, Framer Motion, Supabase).
- **Core Value Proposition:**
  - Strict Clean Architecture standard for long-term maintainability.
  - 60fps high-fidelity animations & modern editorial UX.
  - Automated digital license generation and instant source code (.zip) download.
  - PayOS / VietQR automated instant payment validation.

## 2. Target Audience
1. **Frontend / Fullstack Developers:** Looking for pre-architected, production-grade boilerplates to accelerate client deliverables.
2. **Designers & Solopreneurs:** Looking for high-converting, sleek website foundations without starting from scratch.
3. **Agencies:** Needing reliable, performant, and clean-code templates for client projects.

## 3. Key Surfaces & Routes
- `/`: Interactive Landing Page showcasing hero sandbox, key technical advantages, category filters, featured template showcase, and 3-step checkout workflow.
- `/shop`: Interactive Catalog with search, multi-category chips, price range slider, and tech-stack filters.
- `/product/[id]`: High-fidelity template detail page with interactive live sandbox preview, tech stack accordion, licensing terms, and instant purchase.
- `/cart` & CartDrawer: Slide-over cart and full cart management.
- `/checkout`: 3-Step frictionless digital checkout flow with PayOS VietQR integration.
- `/demo/[id]`: Fullscreen responsive device sandbox for testing templates.
- `/profile` & `/profile/orders`: User dashboard for managing account and downloading purchased `.zip` archives.
- `/admin/*`: Admin dashboard, template management, order tracking, and live translation editor.
